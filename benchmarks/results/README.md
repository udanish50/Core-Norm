# Phase-1 result archive

These CSV files preserve numerical outputs generated during Core-Norm development. Public labels were canonicalized so the proposed method is consistently named **Core-Norm**. A reduced representation used only for scientific ablation is labeled "Core-Norm ablation — residual channel removed"; it is not a separately proposed method.

The archive contains 6,804 classification evaluations and 5,346 regression evaluations from the saved Phase-1 harness, plus robustness-curve summaries. These results are preliminary internal evidence rather than peer-reviewed performance claims.

Conditions in the archive include clean data, missingness, drift, row-wise contamination, and several cell-wise contamination levels. Model families include linear, RBF-kernel, and nearest-neighbor learners.
